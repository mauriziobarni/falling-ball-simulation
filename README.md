# Falling Ball Simulation

A Python file simulation of a falling ball using the forward Euler method.

## About the project

this project simulates the motion of a ball falling under gravity.
the numerical result is compared with the theoretical free-fall solution.

the goal of the project is to explore numerical simulation and understand how the time step affects accuracy.

## Features

- simulates free fall using the Forward Euler method
- calculates height and velocity over time
- calculates the theoretical fall time
- compares simulated and theoretical fall time
- calculates the numerical error
- tests different time-step sizes
- visualizes convergence of the numerical method
- plots height and velocity over time
